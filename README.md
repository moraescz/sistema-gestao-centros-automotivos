# Sistema de Gestão para Centros Automotivos

Sistema interno para gestão de centros automotivos desenvolvido como **Trabalho de Conclusão de Curso (TCC)** no **SENAI**, com foco na organização operacional, controle de estoque, ordens de serviço e gerenciamento de processos internos.

## Sobre o Projeto

O sistema foi desenvolvido para auxiliar centros automotivos na administração do dia a dia, permitindo um controle mais eficiente de clientes, veículos, peças, funcionários e serviços realizados.

O objetivo do projeto é centralizar informações importantes da empresa em uma única plataforma, melhorando organização, produtividade e acompanhamento dos atendimentos.

## Principais Funcionalidades

### Gestão de Clientes e Veículos
- Cadastro de clientes
- Cadastro de veículos
- Histórico completo de atendimentos por veículo
- Consulta de informações relacionadas ao cliente

### Ordens de Serviço (OS)
- Criação e gerenciamento de ordens de serviço
- Controle de status da OS
- Associação de peças e serviços
- Histórico de manutenção

### Controle de Estoque
- Cadastro de peças
- Controle de quantidade disponível
- Movimentação de estoque
- Alertas para estoque baixo

### Sistema de Usuários e Permissões
- Login e autenticação
- Controle de acesso por nível de usuário
- Página de acesso negado para permissões insuficientes

### Dashboard Administrativo
- Indicadores operacionais
- Informações gerais do sistema
- Monitoramento de dados importantes

### Relatórios e Documentos
- Exportação de documentos
- Organização de registros internos

## Tecnologias Utilizadas

- **Python**
- **Django**
- **HTML**
- **CSS**
- **JavaScript**
- **SQLite / MySQL**

## Objetivo do Projeto

Este sistema foi desenvolvido como parte do Trabalho de Conclusão de Curso (TCC) do curso **Técnico em Desenvolvimento de Sistemas do SENAI**, visando aplicar conhecimentos práticos em desenvolvimento web, banco de dados, autenticação de usuários e organização de regras de negócio em um sistema real.
